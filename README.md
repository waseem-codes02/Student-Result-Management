#student Marks management system 


##Project overview 
this is a biginner-friendly database project built using oracle SQL.
it stores student details and marks and allows users to retrieve 
and analyse student results using SQL queries.


##database
- oracle database
- oracle SQL plus 

##Table Details 
Table name: STUDENT_RESULT


Columns : 
- ID: Student ID and primary key 
- NAME: Student name 
- DEPARTMENT: Student deprtment 
- MARKS: Student marks (0 to 100)


##Features
- Store student records
- Display all student details 
- Find student scoring above 80
- Calculate the highest marks 
- Calculate average marks 
- Display PASS and FAIL based on marks 


## SQL Concept Used 
- CREATE TABLE 
- INSERT
- SELECT
- WHERE
- MAX() and AVG()
- CASE 
- PRIMARY KEY 
- CHECK constraint
- COMMIT 


## How to run 
1. Open Oracle SQL Plus.
2. Connect to your Oracle database. 
3. Run the student_result.sql script.
4. Execute the SELECT queries to view the results.
